# Academic Sync

강의 공지에서 학업 일정을 추출해 확인하고 캘린더 파일로 내보내는 반응형 웹 MVP입니다.

## 실행

프로젝트 폴더에서 아래 명령을 실행한 다음 브라우저에서 `http://localhost:8000`을 여세요.

```powershell
py -m http.server 8000
```

정적 HTML/CSS/JavaScript 앱이라 패키지 설치나 빌드 과정은 없습니다.

## 주요 기능

- 과목별 일정 대시보드와 월간 캘린더
- 공지 텍스트에서 날짜, 시간, 과목, 일정 종류 추출
- 일정명과 날짜/시간 수정, 항목 선택
- 같은 날짜·시간의 일정 충돌 처리: 둘 다 유지, 새 일정 시간 조정, 기존 일정 덮어쓰기
- 등록한 일정을 `.ics` 파일로 내보내기
- 브라우저 `localStorage`에 일정 저장
- 모바일 화면과 키보드 조작 지원

## 데모 범위

화면에는 데모 프로필과 연결된 Google Calendar 상태가 표시됩니다. 실제 소셜 로그인/OAuth, LMS 수집, 서버 기반 AI 파싱, Google Calendar API 등록은 연결되어 있지 않습니다. 공지 추출은 브라우저 내 정규식 기반이며, 일정 등록은 캘린더에서 가져올 수 있는 `.ics` 파일을 생성합니다.
